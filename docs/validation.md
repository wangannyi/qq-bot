## 2. 已知依赖提示

在此次解析得到的 `pydantic-settings 2.16.1` 环境中，MCP 初始化会对 `lifespan` 类型提示发出 `IncompleteFieldDefinitionWarning`。该提示没有导致本次测试失败；另行验证了 FastMCP 的工具列举和输入结构生成成功。未通过隐藏警告或关闭校验来通过测试。

升级这些依赖后，应重新检查 MCP 初始化及实际调用。测试环境的成功不能替代生产环境的完整验收。

## 3. 验证边界

测试使用合成资料、临时数据库和替身接口。公开包不包含真实知识库、账号、密钥、聊天回执、原始用户失败记录或赛事私有文档。

此次发布没有恢复自动询问、自动检修或真实 QQ 测试，没有重新启动正式机器人。没有用正式群消息或硬件操作作为发布验证。部署者仍需按 [搭建指南](setup.md) 在自己的允许名单测试群完成真实收发、模型与引用质量验收。

心跳监督与 Resume 是连接恢复措施，不能据此认为外部网络故障已彻底修复，也不能保证历史消息全部恢复。
